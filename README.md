# 시간표 자동 편성 (1차)

HRD 운영계획서와 코드표를 넣으면 직업훈련과정 시간표 파일 3종을 만들어 주는 웹 앱입니다.

- **바로 쓰기**: https://ghost3804.github.io/timetable/ (GitHub Pages를 켠 뒤)
- **내 PC에서 쓰기**: `index.html`을 내려받아 더블클릭 → 크롬이나 엣지로 열기 (인터넷 없이도 동작)

> 넣은 파일은 **각자 PC의 브라우저 안에서만** 처리됩니다. 서버로 올라가거나 저장되지 않습니다.

## 사용 순서

1. **파일 넣기**
   - 운영계획서: HRD 통합심사 신청정보 출력물 (.xls / .xlsx) — NCS 적용 과정과 'NCS 비적용 교과'(이론+실기 시간) 과정 모두 지원
   - 코드표: 강사·시설·교과목 코드가 있는 엑셀 (.xlsx, A~E열)
2. **조건 입력**
   - 개강일, 점심 위치(3교시 뒤 / 4교시 뒤), 수업 교시, 수업 요일, 강의실
   - 과목별 교사 (기본은 운영계획서의 1번 교사) — **'+ 교사 나누기'**로 한 과목을 최대 3명이 시간을 나눠 맡을 수 있음 (1번 교사 시간 → 2번 → 3번 순서로 배정)
   - 과목별 강의실 (비워 두면 과정 기본 강의실)
   - **일괄 등록**: 과목을 체크하고 교사·강의실을 한 번에 넣기
   - 편성 방식: 시간순(교과목 순서대로) 또는 오전·오후 나눠서
   - 공휴일·휴무일 목록 (2026~2027년 공휴일이 미리 들어 있음, 학원 휴무일은 추가)
   - **세부설정 (편성 순서)**: 과목 카드를 끌어 순서를 정함. '오전·오후 나눠서'일 때는 오전 목록/오후 목록 사이로 옮겨 시간대를 바꿈
   - **고정일정**: '고정일정 양식 받기' → 날짜·교시(오전/오후/종일/1-4/5,6)·교과목·교사·강의실·적용 과정을 적어 '고정일정 넣기'. 편성할 때 먼저 자물쇠 칸으로 박히고, 남은 시간만 순서대로 채움. 적용 과정을 비우면 모든 과정, 과정명 일부를 적으면 그 과정만
   - **기준 시간표**: 다른 과정의 편성 저장(.json) 또는 전자시간표(.xlsx)를 여러 개(또는 폴더째) 넣으면, 같은 시간에 교사·강의실이 겹치지 않게 편성하고 겹친 칸은 빨간 테두리로 표시 (교시가 아니라 실제 시각으로 비교하므로 점심 위치가 다른 과정끼리도 검사됨)
   - **전자시간표 불러와서 수정** (첫 화면 네 번째 칸): 이미 만든(또는 HRD에 올린) 전자시간표 .xlsx를 넣으면 미리보기로 되살아남 → 드래그·칸별 교사 바꾸기·칸 고정·개강일만 바꾸기를 그대로 쓰고 ①②③④ 내려받기
     - 점심 위치(3교시 뒤/4교시 뒤)·개강일·수업 교시·요일·기본 강의실을 파일에서 자동으로 맞춤
     - 코드표를 먼저 넣으면 교사·강의실·교과목이 이름으로 보이고, 없으면 코드 그대로 보임(다시 내려받으면 같은 코드로 나감)
     - 운영계획서를 먼저 넣으면 교과목 코드로 과목을 맞춰 구분·NCS 능력단위·계획시간·평가방법(재량교과 제외)이 그대로 쓰임. 없으면 과목별 시간은 시간표에서 세고, 모든 과목을 평가 대상으로 잡음
3. **자동 편성** → 주간 미리보기
   - 칸을 끌어 다른 칸에 놓으면 두 칸이 서로 바뀝니다 (빈 칸으로도 이동 가능)
   - **여유 칸**: 체크한 교시의 앞뒤 1교시(예: 2·3·4교시면 1·5교시)가 빈 칸으로 보입니다. 마지막 날 자투리 1시간을 전날 여유 칸으로 옮기면 수료일이 자동으로 앞당겨집니다
   - 과목별 계획 / 편성 / 과부족, 평가 예정일이 함께 바뀝니다
   - **칸 고정하기**: 켜고 칸을 누르면 고정/풀기. 고정 칸은 드래그로 움직이지 않고, '개강일만 바꾸기'에서도 제자리에 남음. '고정 칸을 양식으로 내보내기'로 다른 과정에 그대로 쓸 수 있음
4. **내려받기**
   - ① 전자시간표 (HRD 업로드용, 샘플과 같은 서식)
   - ② 출력용시간표 (한 장에 한 주 월~금, A4 세로 — 개강 주 월요일부터 수료 주 금요일까지 모든 평일이 들어가고 수업 있는 날에만 시간표 표시, 수업 없는 날은 연한 회색, H2에 담당교사, 페이지 아래 'N주차 / 전체 N주')
   - ③ 평가일정 (성적 파일 '평가날출력-4번' B~W열에 값 붙여넣기)
   - ④ 편성 저장 (.json) — 첫 화면의 **'이어서 수정하기'**에 넣으면 저장했던 상태(드래그로 고친 칸 포함) 그대로 돌아옵니다

## 평가 예정일 규칙

- 본평가: 능력단위별 편성시간의 80%(올림) 시점이 들어 있는 날
- 2차·3차: 앞 평가 + 7일 (수업이 없는 날이면 다음 수업일)
- +7일이 수료일을 넘으면: 앞 평가의 다음 수업일로 연달아 잡음
- 본평가 뒤 남은 수업일이 부족하면: 본평가를 하루 정도 앞당김

- 2차·3차가 같은 날로 겹치면: 본평가 다음 수업일부터 연달아 잡음
- 운영계획서에 평가방법이 비어 있는 과목(예: 재량교과)은 평가일정에서 제외
